# Portfólio — Heitor Imídio
Site estático (HTML + CSS + ES modules, three.js local). Para rodar: `python3 -m http.server` nesta pasta.
- `?fast&l=pt|en` pula a escolha de idioma.
- Áudios: `audio/LIBRARY.md`. Vídeo do primeiro múon: coloque em `video/primeiro-muon.mp4`.
- Modelo 3D: astronauta da NASA (CC BY), `models/astronaut.glb`.
