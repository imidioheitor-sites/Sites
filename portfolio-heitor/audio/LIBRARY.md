# Biblioteca de áudio

24 sons curtos (MP3, ~210 KB no total), sintetizados para este portfólio. Carregados por `js/audio.js` depois do primeiro clique.

| Arquivo | Onde toca |
|---|---|
| click, hover, tick | botões, passar o mouse, textos digitando |
| pop | copiar e-mail, partículas |
| whoosh, whooshdown, swipe | trocas de seção e de projeto |
| riser, ignite, sparkle, note1–note8 | ignição de cores da seção 02 (notas em escala pentatônica, uma por elemento) |
| bleep, build | cursores construindo o site |
| select | escolha do idioma |
| stinger | troca de projeto na seção 04 |
| glitch | transições de tinta e malha |
| ambient | drone de fundo em loop (baixo) |

Para usar uma fala sua: salve `minha-fala.mp3` nesta pasta e chame `Sfx.play('minha-fala')` (ou acrescente em `NAMES`).
