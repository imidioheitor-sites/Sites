# Portfólio · versão Studio

Nova versão do site pessoal de Heitor Imídio. A original (`heitor-imidio.vercel.app`) não foi tocada.

- **Base:** modelo 03 "Editorial Retrato" do artefato *Quinze Modelos React Bits*. O bundle do artefato (`assets/index-7gQDIaob.js` e `.css`) é o código original; só os textos e as imagens foram trocados (o roteador foi fixado nesse modelo).
- **Paleta:** Grafite & Cobre (artefato *Paleta Grafite Cobre*), em `studio.css`.
- **Enxame de cursores:** `js/swarm-build.js` (kit HEsites) constrói a página ao vivo na primeira visita; o botão "Construir com cursores" repete (Esc sai).
- **Efeitos novos** (`js/studio-fx.js`): luz de estúdio de cobre com paralaxe no hero, íris de lente ao entrar em cada seção, rastro de cobre no cursor, barra de progresso e grão de filme.
